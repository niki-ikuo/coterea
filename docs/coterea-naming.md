# Coterea 名称採用資料

**決定事項:** プロダクト正式名称を **Coterea** とする。  
**読み:** 日本語 **コテリア** / 英語公式 **koh-TEH-ree-uh**  
**対象:** 人と AI が集まり、テキストを通じてともに創るワークスペース

---

## 1. 結論

Coterea を正式名称として採用する。

機能名ではなくブランド名として抽象度がちょうどよく、共同作業・コミュニティの意味と結びつく。将来、AI 機能・P2P・Git・エージェントなどを足しても、名前を変える必要がない。

推奨の完成形は次のとおり。

> **Coterea**  
> The collaborative AI text editor.  
> 人と AI が、ともに書き、ともに創る場所。

## 3. 名前の由来と解釈

### 3.1 語源イメージ

英語の *coterie*（親しい仲間・同じ目的を持つ小さなグループ）を連想させる。一般的な英単語そのものではない造語だが、共同体の意味が自然に乗る。

**ブランド解釈:** 人と AI が集まり、文章をともにつくる場所。

### 3.2 頭字語としての説明（対外説明用）

名前自体は機能説明に寄りすぎない。説明が必要な場面では、次のいずれかで補う。

**推奨（製品の核）**

| 要素 | 意味 |
|------|------|
| CO | Collaborative |
| TE | Text Editor |
| REA | Real-time / AI |

> **Coterea** — Collaborative Text Editor for Real-time AI

短くするなら:

> **Coterea** — Collaborative Text Editor + AI

**補足（ローカルワークスペースの性質を出す場合）**

> Collaborative Text Editor  
> Real-time · Local · AI

## 6. 採用理由

1. **共同作業と自然に結びつく**  
   *coterie* の連想から、「人と AI が集まり、文章をともにつくる場所」という解釈が成立する。共同編集エディタのコンセプトと相性がよい。

2. **抽象度がちょうどよい**  
   機能を直接言い過ぎず、無意味な造語でもない。AI エディタ、チームワークスペース、ナレッジ基盤、文書管理、コミュニケーションへ広げても違和感がない。

3. **見た目が整っている**  
   大文字・タイトルケース・小文字のいずれでもバランスがよく、ロゴ・UI・ドメインに使いやすい。

4. **将来性が高い**  
   単語自体が製品説明になりきっていないため、機能追加後も名称を維持できる。

5. **既存ソフトとしての強い使用は確認できていない**  
   今回の検索範囲では、同種のソフトウェア・AI エディタとして強く使われている例は見つからなかった（文献等が中心）。ただし商標の確定調査は別途必須。

## 7. 運用上の注意

1. **発音の揺れ**  
   `-rea` は英語で読みが分かれやすい。公式発音を資料・サイト・音声で固定する。

2. **綴りと音声のギャップ**  
   英語話者は *coterie* を連想しうる。共同体の意味ではプラスだが、スペルを音声で伝えるときは「C-O-T-E-R-E-A」と補う。

3. **タグラインは必須**  
   Coterea 単体では「AI 搭載の共同編集テキストエディタ」までは伝わらない。常にタグラインまたは短い説明を添える。

4. **商標は未確定（ノックアウト調査済み）**  
   2026-08-16 時点の公開情報では **COTEREA 完全一致は見つからなかった**。類似の COTERIE・COTERA・称呼「コトリア」が残る。詳細は [coterea-clearance.md](./coterea-clearance.md)。公式DB再検索と弁理士確認は未了。
