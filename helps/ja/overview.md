# Coterea とは

Coterea は、サーバーを持たない Windows 向けの共同編集テキストエディタです。

メモや Markdown をタブで開き、同一 LAN 上のほかの Coterea と直接つなぎます。右ペインの AI チャットから、開いている文書について質問したり変更を提案できます。
