# 提案の適用

Edit / Agent の返答に変更案が付くことがあります。適用・却下を選んでください。

プレビューのあとで文書が変わっている（共同編集など）と、適用時に差分を今の文書へ載せ直します。重ならない変更なら「再計算」と出て、内容を確認してもう一度適用できます。同じ箇所を両方とも変えていると衝突になり、再計算した差分を確認してから「この内容で適用」するか拒否します。相手の入力を消す全文上書きはしません。
