# Ask / Edit / Agent

送信前にモードを選びます。スレッドごとに最後に使ったモードを覚えます。

- **Ask**: 添付したファイルや選択範囲について、説明・要約・質問に答えます。未添付ならいま開いているタブを使います。ファイルは書き換えません。
- **Edit**: 添付したファイルへの変更案を1つ出します。未添付ならいま開いているタブが対象です。提案カードの適用で文書に入ります。変更のあとに、何を変える提案かを短く文章で報告します。
- **Agent**: 添付があればその本文を渡し、無ければ開いている全タブの本文を渡します。必要ならさらに `list_open_tabs` / `read_tab` で読めます。複数の依頼や長めの作業は `update_todo` でタスクに分け、順番に進めます。ステップ数は設定で上限を決められます。

## コンテキストの添付

次のいずれかで、メッセージ文の途中にカプセル（例: `≡ bin/get-weather.sh:6-10`）を挿入できます。

- ファイルタブを入力欄のカーソル位置へドラッグ＆ドロップ（またはタブの右クリック「チャットに追加」）
- エディタで行を選択して入力欄へドラッグ（または選択範囲の右クリック「チャットに追加」）
- 右クリック「チャット参照をコピー」した内容を、AI チャットへ貼り付け（`path:行-行` 形式でも可）

カプセルがあるときは、その添付だけがコンテキストになります。無いときの既定は Ask / Edit がカレントタブ、Agent が開いている全ファイルです。
