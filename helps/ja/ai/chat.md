# AI チャット

`Ctrl+\` またはタイトルバー右のパネルボタンで AI パネルを開きます。

会話はスレッド（タブ）単位です。＋で新規、履歴アイコンから過去の会話を再開できます。×でタブから外します。

使うには設定の AI でプロバイダとモデルを選び、必要な場合は API Key を保存します。Key は端末内に保存され、チャット画面には出ません。

ファイルタブや、エディタで選んだ行を入力文の途中へドロップするか、右クリックの「チャットに追加」でコンテキストがカプセルとして入ります。「チャット参照をコピー」した行指定をチャットへ貼り付けることもできます。未添付のとき、Ask / Edit / Agent ともカレントタブを使います。Agent は他に開いているタブの一覧だけ添え、必要な本文はツールで読みます。

Agent モードでは、複数の依頼があると計画パネルにタスクが並び、完了するまで順に進めます。
