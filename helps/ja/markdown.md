# Markdown

`.md` ファイルではタブ直下で「編集 / 分割 / プレビュー」を切り替えられます。

表示メニューの「Markdown の見出し」をオンにすると、左側に見出し一覧が出ます。クリックでその位置へジャンプします。

分割表示では、見出し単位でソースとプレビューのスクロールを同期します。
