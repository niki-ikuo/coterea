# Coterea

**Coterea** — The collaborative AI text editor.  
人と AI が、ともに書き、ともに創る場所。

Windows 向けのテキストエディタです。ローカルファイルをタブで開き、同一 LAN 上のほかの Coterea とサーバーなしで共同編集できます。右ペインの AI チャットから、開いている文書について質問したり、変更案を適用できます。

詳細な製品仕様は [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 必要環境

- Windows 10 / 11（x64）
- Node.js 22 以降（開発時）

## 開発

```bash
npm install
npm run dev
```

共同編集の確認用に、別のユーザーデータで 2 つ目のウィンドウを起動できます。

```bash
npm run dev:second
```

## 主な操作

| 操作 | キー |
| --- | --- |
| 新規 | Ctrl+N |
| 開く | Ctrl+O |
| 保存 | Ctrl+S |
| AI パネル | Ctrl+\ |
| ヘルプ | F1 |
| ズーム | Ctrl++ / Ctrl+- / Ctrl+0 |

- **表示 → ミニマップ** … エディタ右端の文書全体図
- **表示 → Markdown の見出し** … Markdown の見出し一覧
- **ヘルプ → ヘルプを開く / AIヘルプ** … 検索できるヘルプと、記事を根拠にした AI Q&A
- チャットの **履歴** … 閉じた会話を再開、または完全に削除

設定は「ファイル → 設定」またはタイトルバー右の歯車から開きます。AI を使う場合は、プロバイダとモデル、必要な API Key を設定してください。Key は端末内に保存されます。

## 共同編集について

共同編集は端末同士の直接接続です。Coterea のクラウドへ文書は送りません。公開 Wi-Fi では使わないでください。
